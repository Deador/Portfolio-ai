### Showreel: фиксированная коробка слота, устранён сдвиг контента при ротации (28.08.2026)

Владелец обнаружил, что при ротации кадров showreel (каждые 4с, `useShowreel`) весь сайт «дёргается» —
проведён анализ, отчёт согласован, реализован выбранный вариант.

**Причина:** `.showreel` не имел фиксированного размера — высота коробки определялась натуральной
пропорцией активного кадра (`height: auto`). У кадров разные пропорции (showreel-1/2 ≈1.532, showreel-3
≈1.444) → высота слота скакала между ~376px и ~400px (разница ~23px) при каждой смене на кадр 3 и
обратно, сдвигая scroll-индикатор/заголовок/CTA внутри hero и всю страницу ниже hero (Cumulative Layout
Shift). Дополнительно уходящий кадр при кроссфейде (`object-fit: cover`) на 0.6с растягивался/обрезался
под уже изменившуюся коробку — второй, более мелкий артефакт поверх основного прыжка.

**Решение (вариант A из отчёта):** `.showreel` получил фиксированный `aspect-ratio: 1216 / 794`
(пропорция кадров 1–2, совпадает с исходным Figma-слотом) вместо резиновой высоты. Кадры переведены на
`position: absolute; inset: 0; object-fit: contain` — вписываются в неизменную коробку без обрезки;
кадр 3 (иная пропорция) получает небольшие поля по бокам (~16px) вместо того чтобы менять размер слота.
`.frameLeaving` упрощён (position/width/height/object-fit унаследованы от базового класса, остаётся
только анимация затухания) — заодно устранён и артефакт кроссфейда. Комментарии в коде обновлены.

Компромисс: осознанное решение с 22.08.2026 «не обрезать кадры ни при каких условиях» частично
пересмотрено в пользу «не дёргать layout» — кадр 3 теперь вписывается с полями, а не обрезается и не
растягивает коробку; при получении от дизайнера ассета в правильной пропорции (уже в open issues) поля
исчезнут сами.

Проверки: `type-check` ✅, `lint` ✅, `build` ✅, `build-storybook` ✅. Визуальная проверка ротации в
браузере — за владельцем (нет Playwright/Chromium в окружении).

**Файлы:** `src/app/pages/Home/sections/HomeHero/HomeHero.module.scss`,
`src/app/pages/Home/sections/HomeHero/HomeHero.tsx` (только комментарий).
